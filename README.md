# Әдебиет сұрақ-жауап боты (Мазмұн мен пішін)

Бұл жобада берілген 14 сұрақ-жауапқа негізделген 2 түрлі бот нұсқасы дайындалған:

### 1. 🌐 Веб Чат-Бот (Интерактивті веб-интерфейс)
Ешқандай сервер немесе қосымша орнатуды қажет етпейді!
- **Файл:** [`index.html`](file:///C:/Users/user/.gemini/antigravity/scratch/kazakh_literature_bot/index.html)
- **Мүмкіндіктері:**
  - 14 сұрақтың дайын батырмалары (chips).
  - Сұрақты шерткенде пайдаланушы хабарламасы ретінде жіберіліп, бот жазу анимациясын (typing indicator) көрсетіп жауап береді.
  - Мәтін жазып іздеу: кілт сөзді (мысалы: *Фемида*, *пішін*, *1*) жазғанда тиісті жауапты автоматты түрде табады.
  - Қазіргі заманғы заманауи дизайн (Dark mode, gradient, responsive).

**Қалай ашуға болады:**
Кез келген браузерде (Chrome, Edge, т.б.) [`index.html`](file:///C:/Users/user/.gemini/antigravity/scratch/kazakh_literature_bot/index.html) файлын ашыңыз.

### 2. 🤖 Telegram Бот (Python / aiogram)
Telegram мессенджерінде нағыз бот ретінде жұмыс істеуге арналған.
- **Файл:** [`telegram_bot.py`](file:///C:/Users/user/.gemini/antigravity/scratch/kazakh_literature_bot/telegram_bot.py)
- **Мүмкіндіктері:**
  - `/start` басқанда 14 сұрақтың батырмалары (`InlineKeyboard`) шығады.
  - Пайдаланушы батырманы басқанда жауап ашылып, "Артқа қайту" батырмасы ұсынылады.
  - Сұрақ нөмірін жазса да автоматты түрде жауап қайтарады.

**Іске қосу қадамдары:**
```bash
# 1. Қажетті кітапхананы орнату:
pip install aiogram

# 2. telegram_bot.py ішіндегі BOT_TOKEN мәніне өз ботыңыздың токенін қойыңыз:
# (@BotFather арқылы алынады)

# 3. Ботты іске қосу:
python telegram_bot.py
```
